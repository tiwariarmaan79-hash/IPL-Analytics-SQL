# IPL-Analytics-SQL
MySQL-based IPL analytics project using joins, aggregate functions, subqueries and views to generate cricket performance insights.

# IPL Analytics SQL Project

## Overview

A MySQL-based IPL analytics project designed to analyze
teams, players and match performance using SQL queries.

## Database Tables

- Teams
- Players
- Matches

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- INNER JOIN
- Subqueries
- Views

## Business Questions Solved

- Highest run scorer
- Team-wise total runs
- Matches won by each team
- Mumbai Indians match analysis
- Players above average runs
- Top batsmen view
